Outfitter Asset Helper

Add a creature, mount or outfit: check the sprite and preview it before you publish it.

This page does not change the Outfitter by itself. It checks your sprite and prepares the files. Nothing is saved or published until you upload them to GitHub (step 6). Reloading this page clears everything. Full guide

1. What are you adding?

2. Name

Spaces become underscores. Capital letters matter: the sprite file gets exactly this name.

3. Sprite sheet

A PNG image of the whole sprite sheet (frames of 64 x 64 pixels; pure magenta #FF00FF is transparent). An existing .txt sprite file works too.

4. Settings

Choose a sprite sheet and the settings are filled in from its size. Check them in the preview.

5. Check and preview

    Preview only - this copy of the Outfitter shows your item, nobody else sees it. Change settings above and press "Show preview" again to update it.
